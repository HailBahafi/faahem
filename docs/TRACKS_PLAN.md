# خطة مسارات اللغات: من الأساسيات إلى الاحتراف

قرار المستخدم (2026-11-21): ست لغات معاً (JavaScript و TypeScript و Python و Go و Rust و Dart/Flutter)،
لكل لغة مسار كامل من الأساسيات إلى الاحتراف، وكود Go و Rust و Dart يعمل فعلاً عبر **خادم تشغيل صغير**.

## الشكل

- المسار الحالي (13 مرحلة) يبقى كما هو: مفاهيم عامة (الحاسوب، الويب، قواعد البيانات، النشر...).
- يضاف **مسار لكل لغة** في `/tracks/<lang>`، فيه أربعة مستويات:
  **أساسيات ← متوسط ← متقدم ← احتراف**. كل مستوى 6–10 دروس ومشروع، وشهادة عند إتمامه.
- كل درس بنفس النموذج الحالي: المشكلة، المشهد المتحرك، الملعب، توقّع، الكود، التطبيق، الاختبار (80%).
- لا تكرار: الدرس الموجود يُربط من المسار بدل إعادة كتابته (مثلاً أساسيات JS هي دروس المرحلة 1،
  و `ownership` و `borrowing` و `concurrency` داخل مسار Rust).
- دروس المسار بلغته فقط (`singleLanguage`)، بأسماء `py-…` و `go-…` و `rs-…` و `ts-…` و `dart-…` و `js-…`.
- المستوى الاحترافي يُبنى حول ما يفعله المحترف فعلاً: الاختبارات، الأداء والقياس، تصميم الكود، الأدوات، ومشروع حقيقي.

## البنية التقنية (المرحلة T0، قبل المحتوى)

1. **نموذج المسارات:** `src/content/tracks.ts` (لغة، مستويات، دروس، مشروع)، صفحة `/tracks` وصفحة لكل لغة،
   رابط في الرئيسية والهيدر، وتقدّم وشهادة لكل مستوى (نفس منطق شهادة المرحلة).
2. **خادم التشغيل:** Piston (مفتوح المصدر) على خادم صغير منفصل، يشغّل Go و Rust و Dart داخل حاويات معزولة
   بحدود وقت وذاكرة وبلا شبكة. الموقع يناديه عبر `/api/run` (حد طلبات لكل مستخدم، متغير `RUN_SERVICE_URL`).
   `RunLang` يضاف إليه `go` و `rust` و `dart`. بدون الخادم تعمل هذه التمارين كترتيب وإكمال كما الآن.
   - يحتاج خادماً (VPS صغير، تقريباً 4–6 دولار شهرياً، أو مجاني مثل Oracle Free Tier): **قرار المستخدم**.
     لا يُستخدم خادم InfluenceRadar.
3. **المدقق:** `check-lessons` يشغّل حلول Go و Rust و Dart عبر خادم التشغيل أو الأدوات المحلية.
4. **المشاهد:** JS و Python لهما متتبّع تلقائي. Go و Rust و Dart مشاهدها مكتوبة يدوياً (الذاكرة والمكدّس خطوة بخطوة)،
   وهو ما يدعمه `ScenePlayer` اليوم.

## المناهج

### JavaScript (`js-`)
- **أساسيات:** دروس المرحلة 1 الحالية (15 درساً).
- **متوسط:** الإغلاق closures · `this` · النماذج الأولية والأصناف · الوحدات ESM · دوال المصفوفات العليا map/filter/reduce ·
  التفكيك والنشر · Map و Set و WeakMap · المكرّرات والمولّدات · التعابير النمطية · التاريخ و Intl.
- **متقدم:** حلقة الأحداث (موجود) · الوعود من الداخل · async iterators · الذاكرة وجامع القمامة · Proxy و Reflect ·
  Symbol · الأنماط الوظيفية وعدم التغيّر · أنماط التصميم · Streams في Node.
- **احتراف:** الاختبارات (Vitest) · الأدوات (npm، bundlers، lint) · Node من الداخل (fs، process، workers) ·
  الأمان (XSS، prototype pollution) · القياس والتحسين · تنظيم مشروع كبير.

### TypeScript (`ts-`)
- **أساسيات:** لماذا الأنواع · التعليقات النوعية · interface و type · الاتحادات والتضييق · الدوال · المصفوفات و tuples ·
  الأنواع الحرفية و enum · tsconfig.
- **متوسط:** Generics · الأنواع المساعدة · الأصناف ومحددات الوصول · type guards · الاتحادات المميّزة · ملفات التعريف `.d.ts`.
- **متقدم:** الأنواع الشرطية · mapped types · template literal types · `infer` · الأنواع الموسومة branded · decorators.
- **احتراف:** إعدادات strict · كتابة أنواع مكتبة · APIs آمنة النوع (zod) · ترحيل مشروع JS إلى TS · monorepo و project references.

### Python (`py-`)
- **أساسيات:** المتغيرات أسماء لكائنات · الأنواع · العمليات · الشروط · الحلقات · الدوال · القوائم · tuples ·
  القواميس · المجموعات · النصوص · الأخطاء · الملفات.
- **متوسط:** comprehensions · الأصناف · الدوال الخاصة dunder · الوراثة · الوحدات والحزم · المكرّرات والمولّدات ·
  الاستثناءات المخصّصة · المكتبة القياسية · venv و pip.
- **متقدم:** decorators · context managers · dataclasses · typing · asyncio · threads و processes و GIL ·
  نموذج الذاكرة وعدّ المراجع · descriptors.
- **احتراف:** pytest · التحزيم pyproject · القياس والتحسين · logging والإعدادات · FastAPI بعمق · أداة CLI · جودة الكود (ruff و mypy).

### Go (`go-`)
- **أساسيات:** الأداة go · المتغيرات والقيم الصفرية · الأنواع · التحكم · الدوال وتعدّد القيم · المصفوفات و slices من الداخل ·
  maps · النصوص و runes · structs · المؤشرات.
- **متوسط:** methods · interfaces · الأخطاء كقيم · الحزم و modules · defer و panic و recover · generics · الاختبارات.
- **متقدم:** goroutines · channels · select · sync و mutex · context · الذاكرة و escape analysis · جامع القمامة.
- **احتراف:** خدمات HTTP · database/sql · pprof · benchmarks · أنماط التزامن (worker pool، pipeline) · تنظيم المشروع والنشر.

### Rust (`rs-`)
- **أساسيات:** cargo · المتغيرات والتغيّر · الأنواع · الدوال · التحكم · الملكية (موجود) · الاستعارة (موجود) · slices ·
  structs · enum و match · Option و Result.
- **متوسط:** المجموعات · النصوص · معالجة الأخطاء و `?` · الوحدات والـ crates · traits · generics · lifetimes ·
  iterators و closures · الاختبارات.
- **متقدم:** Box و Rc و RefCell · interior mutability · التزامن (موجود) · Send و Sync · async و tokio · macros · unsafe و FFI.
- **احتراف:** الأداء و zero-cost · القياس · تصميم API · workspaces · خدمة ويب (axum) · أداة CLI (clap) · WebAssembly.

### Dart و Flutter (`dart-`)
- **أساسيات Dart:** Dart (موجود) · المتغيرات و null safety · الأنواع · التحكم · الدوال · المجموعات · النصوص · الأصناف.
- **متوسط:** المُنشئات · الوراثة و mixins · generics · Future و Stream · isolates · الأخطاء ·
  Flutter: Widgets (موجود) · التخطيط · الحالة (موجود) · التنقّل · النماذج.
- **متقدم:** إدارة الحالة (Riverpod أو Bloc) · الاتصال بالـ API (موجود) · التخزين المحلي · الأنميشن · الرسم المخصّص · platform channels.
- **احتراف:** اختبارات widget و integration · معمارية التطبيق · الأداء · RTL والترجمة وإمكانية الوصول · النشر على المتاجر و CI.
